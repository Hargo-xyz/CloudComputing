Apa Itu
Cloud Computing?

Secara sederhana, cloud computing adalah layanan menyewa infrastruktur komputasi (server, penyimpanan, basis data, dan jaringan) melalui internet secara fleksibel.

Tanpa perlu membeli atau merawat perangkat keras fisik yang mahal, Anda dapat menggunakan sumber daya TI berskala global secara instan dengan model pembayaran sesuai penggunaan (Pay-as-you-go).

Infrastructure Archive // Timeline

Evolusi Arsitektur.

Transisi struktural dari pengelolaan *bare-metal* secara mandiri menuju elastisitas ekosistem komputasi awan modern.

EPOCH: 1990-2000

On-Premise

Status: Legacy | CapEx Heavy

Organisasi wajib melakukan pengadaan, instalasi, dan pemeliharaan server fisik (bare-metal) secara mandiri di fasilitas internal. Membutuhkan belanja modal yang masif dan waktu *deployment* berbulan-bulan.

EPOCH: 2001-2010

Virtualization

Status: Transition | Resource Optimized

Implementasi layer *Hypervisor* (seperti VMware/KVM) mengizinkan satu mesin fisik dipecah menjadi multiple Virtual Machines (VM). Utilisasi perangkat keras meningkat drastis, memangkas *footprint* fisik data center.

EPOCH: PRESENT

Cloud Computing

Status: Active standard | OpEx / Elastic

Infrastruktur disediakan sebagai layanan (*Infrastructure as a Service*) melalui API. Kapasitas komputasi dapat di-skala (scale-up/down) secara otomatis dalam hitungan detik dengan model penagihan *pay-as-you-go*.

Arsitektur Fundamental

5 Pilar Cloud Computing
01

On-Demand
Self-Service

Kemandirian adalah kunci. Pengguna dapat secara instan menyediakan kapasitas komputasi secara sepihak tanpa interaksi manusia.

02

Broad
Network Access

Akses tanpa batas geografi. Kapabilitas layanan tersedia di seluruh jaringan dan dapat diakses dari berbagai jenis perangkat endpoint.

03

Resource
Pooling

Sistem berbagi secara cerdas. Sumber daya komputasi digabungkan untuk melayani multi-penyewa dengan model fisik dan virtual dinamis.

04

Rapid
Elasticity

Sistem yang bernapas. Kapasitas dapat dialokasikan dan dirilis secara elastis untuk mengimbangi fluktuasi demand.

05

Measured
Service

Transparansi meteran utilitas. Penggunaan cloud dimonitor, dikontrol, dan dilaporkan secara otomatis bagi pengguna.

Infrastruktur masa depan, siap hari ini

Pendekatan cloud modern menghapus batasan fisik. Setiap resource dirancang untuk menopang beban kerja kritikal dengan tingkat ketersediaan tinggi, memberikan Anda pondasi digital yang kokoh.

Tim IT kini bisa berfokus pada inovasi dan pengembangan produk. Penyedia layanan cloud menangani kompleksitas infrastruktur, skalabilitas, dan keamanan secara otomatis di belakang layar.

Model Layanan Cloud

Arsitektur infrastruktur terdistribusi yang dapat disesuaikan dengan kebutuhan Anda.

↗

IaaS

Infrastructure as a Service. Akses bare-metal virtual dengan kendali penuh atas OS, komputasi, dan jaringan.

↗

PaaS

Platform as a Service. Fokus penuh pada deployment aplikasi tanpa pusing memikirkan manajemen server.

↗

SaaS

Software as a Service. Solusi aplikasi siap pakai berskala global yang langsung dapat diakses via peramban web.
